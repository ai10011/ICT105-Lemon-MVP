# Digital Go-to-Market Plan

## Product / Prototype Name
LostLink
## Target Early Users
The first users are university students who frequently lose or find items on campus. Campus security staff and student club members can also test the prototype and provide feedback.

## Main Value Proposition
A simple platform that helps students quickly report, search, and track lost and found items in one place.

## Channel Plan

| Channel | Target User | Message Angle | User Action Expected | Metric to Track | Why This Channel Fits |
| --- | --- | --- | --- | --- | --- |
| Class chat group | Students | Stop searching multiple chat groups for lost items | Click prototype link | Number of clicks | Students use class chat groups every day |
| Campus poster with QR code | Students on campus | Report or search for lost items in seconds | Scan QR code | QR scans | Reaches users where items are commonly lost |
| Campus Facebook Page post | Students | Find lost items faster with one simple website | Visit prototype | Post views and link clicks | Many students regularly visit Facebook Page|

## Launch Sequence
1. Prepare the landing page and prototype link.
2. Share the link in class chat groups.
3. Display posters with QR codes around campus.
4. Collect feedback using a Google Form.
5. Improve the prototype based on user feedback.

## Risk and Mitigation

| Risk | Mitigation |
| --- | --- |
| Students ignore the prototype | Use short and clear messages with a simple call-to-action. |
| Low number of testers | Ask classmates, friends, and student clubs to participate. |
| Users encounter bugs | Test the prototype before sharing and fix issues quickly. |
| QR code or link does not work | Test all links and QR codes before launch. |
