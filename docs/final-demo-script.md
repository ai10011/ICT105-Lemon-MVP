# Final Demo Script

## Demo Duration
Recommended duration: 5-7 minutes.

## 1. Opening
Introduce the project title, problem, target users, and value proposition.

## 2. User Scenario
Describe the realistic situation where the user needs the system.

## 3. Prototype Walkthrough
| Step | Screen/Feature | What to Demonstrate | Requirement ID |
|---|---|---|---|
| 1 | Homepage | Show title, target user, problem, and main action | FR-01 |
| 2 | Input form | Submit a record/request/report | FR-03 |
| 3 | Record list | View stored/simulated records | FR-05 |
| 4 | Search/filter | Search or filter records | FR-06 |
| 5 | Detail view | View details of a selected record | FR-07 |
| 6 | Admin/status | Update or view status | FR-08, FR-09 |
| 7 | Dashboard/metrics | Show summary or product metric | FR-11 |

## 4. Evidence and Validation
Briefly explain what users tested and what evidence was collected.

## 5. Closing
Summarize final value, improvements made, and future work.
