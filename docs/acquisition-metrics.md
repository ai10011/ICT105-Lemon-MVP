# Acquisition Metrics

## Purpose
Define how the group will measure early user interest and landing page performance.

## Required Metrics

| Metric ID | Metric Name | What It Measures | Formula / Counting Method | Data Source | Target / Success Criterion |
| --- | --- | --- | --- | --- | --- |
| M-01 | Landing page views | Number of people who opened the landing page | Count page views manually, using form logs, or simulated tracking | Landing page / spreadsheet | Example: at least 20 views |
| M-02 | CTA clicks | Number of users who clicked the main button | CTA clicks / page views | landing page script / manual count | Example: 30% click rate |
| M-03 | Demo attempts | Number of users who opened or tested the prototype | Count demo visits | prototype link / form | Example: 10 attempts |
| M-04 | Feedback responses | Number of users who gave feedback | Count submitted feedback forms | Google Form / sheet | Example: 5 responses |
| M-05 | Interest conversion | Percentage of visitors who took the target action | target actions / page views * 100 | spreadsheet | Example: 20% conversion |

## Interpretation
What will the group do if the metrics are weak?

Examples:
- Improve headline
- Change CTA text
- Simplify prototype flow
- Use a more relevant user channel
- Clarify benefit statement
