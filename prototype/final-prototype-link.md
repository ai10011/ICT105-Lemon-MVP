## Specifications
- **Prototype Platform / Tool**: HTML5 / Vanilla CSS / JavaScript / Node.js Express server (`prototype/project/`)
- **Login / Access Instructions**: No login required for public browsing. Public access allows searching items (`records.html`), submitting lost/found item reports (`form.html`), and viewing item details (`detail.html`). Admin/staff management portal is accessible via header navigation or direct link ([`admin.html`](project/admin.html)).
- **Notes for Lecturer**: Pre-populated with representative mock-up campus lost and found item records (Student IDs, calculators, keys, headsets across campus locations) for instant evaluation of multi-criteria search, location filters, detail views, and admin status updates. Dynamic data persists locally in the browser via `localStorage`.
