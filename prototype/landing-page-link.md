## Notes
The landing page (`index.html`) acts as the front gateway for the **Lemon - Smart Campus Lost-and-Found System**. It communicates the project headline, subheadline value proposition, and key target benefits directly to students and campus staff. 

When users click the main CTAs on the landing page:
1. **Try Demo / Search Lost Items**: Instantly launches the interactive lost-and-found directory catalog (`records.html`), enabling real-time filtering by campus building dropdowns, category, and claim status.
2. **Submit Test Report**: Opens the reporting input form (`form.html`), guiding users through privacy-compliant submission with mandatory field validations (`FR-03`, `FR-10`).
3. **Admin & Analytics**: Header navigation links seamlessly connect the landing page to the staff status management portal (`admin.html`) and system analytics dashboard (`dashboard.html`).
